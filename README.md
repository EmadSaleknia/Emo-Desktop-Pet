# Emo Desktop Pet 🤖

An interactive Emo desktop pet built with Python and PyQt5. It reacts to typing, eats unneeded files, and plays around your screen!

### ✨ Features
- **Trash Eater:** Drag and drop unwanted files on Emo to send them directly to the Recycle Bin.
- **Typing Sync:** Types on its own mini-monitor when you type on your keyboard.
- **Interactive:** Double-click to pet, or click 4 times fast to make it dizzy.
- **Random Behaviors:** Roaming, reading, cleaning the screen, and even a disco mode!

### 🚀 How to Run
1. Install requirements:
   ```bash
   pip install PyQt5 pynput psutil send2trash

2. Run the main script:
   ```bash
   python main.py


Or simply download the portable .exe from the Releases section!
